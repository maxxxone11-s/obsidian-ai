# Параметр efConstruction

Область: [[Vector Databases/Vector Databases|Vector Databases]]

## Академическое определение

`efConstruction` определяет размер списка кандидатов, исследуемых при поиске соседей для нового embedding во время построения HNSW-индекса.

## Инженерное назначение

Параметр повышает качество графа за счёт более тщательного выбора соседей для новых узлов.

## Причина существования

Если выбирать связи из слишком малого количества кандидатов, граф может получить неудачные соседства и ухудшить последующую навигацию.

## Простое объяснение

`efConstruction` отвечает не за итоговое количество связей, а за качество выбора этих связей.

## Как это работает

При добавлении нового embedding алгоритм:

1. исследует до `efConstruction` кандидатов;
2. выбирает среди них лучших соседей;
3. сохраняет не более `M` связей.

После завершения построения индекса `efConstruction` больше не участвует в обработке поисковых запросов.

## Пример

При `M = 16` и `efConstruction = 20` лучшие 16 соседей выбираются из 20 кандидатов. При `efConstruction = 300` число связей остаётся тем же, но выбор выполняется из 300 кандидатов и потенциально формирует более качественный граф.

## Типичные ошибки

- Путать `efConstruction` с `efSearch`.
- Считать, что `efConstruction` используется при каждом запросе.
- Считать, что он определяет итоговое количество связей вместо `M`.
