# Greedy Search в HNSW

## Академическое определение

Greedy Search в HNSW — стратегия навигации, при которой на каждом шаге выбираются наиболее перспективные соседи среди доступных узлов.

## Инженерное назначение

Жадная стратегия позволяет быстро приближаться к области наиболее похожих embeddings без исследования всего графа.

## Причина существования

Полный просмотр графа уничтожил бы преимущество ANN. Выбор наиболее перспективных направлений сокращает стоимость поиска.

## Простое объяснение

На каждом шаге алгоритм продолжает движение туда, где результат выглядит ближе к запросу.

## Как это работает

1. Для текущего узла рассматриваются его соседи.
2. Их similarity сравнивается с запросом.
3. Лучшие кандидаты становятся направлениями дальнейшего поиска.
4. Процесс повторяется, пока улучшение возможно.

## Пример

Упрощённо путь выглядит как `текущий узел → лучший сосед → следующий лучший сосед`. В HNSW одновременно сохраняется несколько перспективных кандидатов, чтобы не зависеть от одного маршрута.

## Типичные ошибки

- Считать, что Greedy Search строит заранее известный глобально оптимальный маршрут.
- Думать, что алгоритм заранее знает весь путь.
- Сводить реальный HNSW к единственному лучшему соседу на каждом шаге.
