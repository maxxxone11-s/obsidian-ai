# Recall в Approximate Nearest Neighbor

## Академическое определение

Recall в ANN — метрика качества приближённого поиска, показывающая, какую долю действительно ближайших соседей удалось найти по сравнению с результатом Exact Search.

## Инженерное назначение

Метрика используется для оценки качества настройки ANN-индекса и выбора компромисса между скоростью поиска и точностью результата.

## Причина существования

ANN не гарантирует идеальный результат, поэтому потерю качества необходимо измерять количественно относительно точного эталона.

## Простое объяснение

ANN Recall показывает, сколько правильных соседей приближённый поиск вернул из тех, которые нашёл бы полный перебор.

## Как это работает

1. Для тестового запроса выполняется [[Vector Databases/Exact Search|Exact Search]], который считается эталоном.
2. Тот же запрос выполняется через ANN-индекс.
3. Top-K двух методов сравниваются.
4. Чем больше совпадений, тем выше Recall и тем качественнее настройка индекса.

## Пример

Exact Search вернул `A, B, C, D, E`, а ANN — `A, B, C, D, F`. ANN потерял одного из пяти действительно ближайших соседей, поэтому Recall ниже 100%.

## Типичные ошибки

- Использовать Recall как метрику скорости.
- Считать его рабочей метрикой каждого пользовательского запроса, а не evaluation-метрикой на тестовом наборе.
- Путать Recall с Cosine Similarity.
- Путать ANN Recall с Retrieval Recall в RAG.
