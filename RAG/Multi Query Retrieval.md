# Multi Query Retrieval

## Академическое определение

Multi Query Retrieval — техника Query Transformation, генерирующая несколько независимых вариантов пользовательского запроса и выполняющая отдельный retrieval для каждого варианта с последующим объединением результатов.

## Инженерное назначение

Техника исследует несколько областей embedding space и повышает вероятность найти документы, которые одна формулировка запроса могла бы пропустить.

## Причина существования

Один запрос выражает намерение только одной формулировкой. Разные аспекты темы и способы её описания могут находиться в других областях семантического пространства.

## Простое объяснение

Вместо одного поиска система формулирует несколько разных вопросов, выполняет поиск для каждого и объединяет найденные документы.

## Как это работает

1. LLM генерирует несколько независимых вариантов исходного вопроса.
2. Для каждого варианта строится embedding.
3. [[RAG/Retrieval|Retrieval]] выполняется `N` раз.
4. Результаты дедуплицируются и объединяются через fusion, например [[RAG/Reciprocal Rank Fusion (RRF)|RRF]].
5. [[RAG/Reranking|Reranker]] уточняет общий порядок кандидатов.

## Пример

Запрос «Docker» превращается в вопросы «Что такое Docker?», «Как работает контейнеризация?», «Как запустить Docker Container?» и «Какие преимущества даёт Docker?».

## Типичные ошибки

- Путать несколько независимых запросов с расширением одного запроса терминами.
- Игнорировать рост стоимости embedding и retrieval.
- Не дедуплицировать и не объединять результаты нескольких поисков.
- Генерировать варианты, которые не отражают исходное намерение.
