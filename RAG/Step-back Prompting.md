# Step-back Prompting

## Академическое определение

Step-back Prompting — техника Query Transformation, создающая более общий вопрос о фундаментальной концепции, лежащей в основе исходного конкретного запроса.

## Инженерное назначение

Техника помогает retrieval находить объяснения базовых принципов, необходимых для ответа на узкий технический вопрос.

## Причина существования

Конкретная формулировка может совпадать только с документацией API и не находить материалы о лежащем в основе механизме. Более общий вопрос расширяет поиск на фундаментальный уровень.

## Простое объяснение

Система делает шаг назад: от частного вопроса переходит к общей идее, которая объясняет этот частный случай.

## Как это работает

1. Получает исходный технический вопрос.
2. Определяет фундаментальную концепцию, необходимую для понимания.
3. Формирует более общий вопрос, сохраняя связь с исходным намерением.
4. Строит embedding общего вопроса.
5. Retriever ищет фундаментальные материалы.

## Пример

Вопрос «Как работает Depends в FastAPI?» преобразуется в «Что такое Dependency Injection в веб-фреймворках?».

## Типичные ошибки

- Делать вопрос настолько общим, что он теряет связь с исходной задачей.
- Подменять фундаментальную концепцию простым описанием технологии.
- Путать один общий вопрос с несколькими независимыми запросами [[RAG/Multi Query Retrieval|Multi Query Retrieval]].
- Использовать Step-back как финальный ответ пользователю.
