# Hybrid Search

## Академическое определение

Hybrid Search — подход, объединяющий результаты семантического dense-поиска и лексического sparse-поиска для повышения качества retrieval.

## Инженерное назначение

Hybrid Search сочетает поиск по смыслу с точными совпадениями терминов, идентификаторов, версий, кодов ошибок и редких имён.

## Причина существования

Embeddings хорошо отражают естественный язык, но могут пропускать точные значения. Keyword Search надёжен для совпадений строк, но хуже понимает перефразирование и смысл.

## Простое объяснение

Система ищет документы двумя способами — по смыслу и по словам — а затем объединяет два ранжированных списка.

## Как это работает

1. Запрос поступает в Semantic Search и Keyword Search.
2. Каждый поиск возвращает собственный ранжированный список.
3. Результаты нормализуются или объединяются алгоритмом ранговой агрегации.
4. Итоговые кандидаты могут пройти [[RAG/Reranking|reranking]].

## Пример

Код ошибки `ORA-12541` лучше находится Keyword Search, а запрос «Как приготовить пасту?» может лучше работать через Semantic Search. Hybrid Search использует сильные стороны обоих каналов.

## Типичные ошибки

- Использовать только Semantic Search для любых данных.
- Использовать только Keyword Search и терять смысловые совпадения.
- Считать объединение простой конкатенацией списков.
- Не оценивать вклад каждого канала на целевых запросах.
