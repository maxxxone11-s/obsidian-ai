# Reciprocal Rank Fusion (RRF)

## Академическое определение

Reciprocal Rank Fusion — алгоритм объединения нескольких ранжированных списков, который назначает документу суммарный балл на основе обратных величин его позиций в каждом списке:

\[
RRF(d) = \sum_i \frac{1}{k + r_i(d)}
\]

где \(r_i(d)\) — позиция документа в списке \(i\), а \(k\) — сглаживающая константа, часто около 60.

## Инженерное назначение

RRF объединяет выдачу Semantic Search и Keyword Search без прямого сравнения их несовместимых raw scores.

## Причина существования

Оценки разных поисковых систем могут иметь разные шкалы и смысл. Простое сложение или усреднение raw scores способно исказить итоговый порядок, тогда как позиции внутри каждого списка уже выражают относительную уверенность соответствующего retriever.

## Простое объяснение

Документ получает тем больше баллов, чем выше он стоит в каждом списке. Если он высоко ранжирован сразу несколькими поисками, его баллы накапливаются.

## Как это работает

1. Несколько retrievers независимо формируют ранжированные списки.
2. Для каждого появления документа берётся его rank, а не исходный score.
3. Позиция преобразуется в вклад `1 / (k + rank)`.
4. Вклады документа из всех списков суммируются.
5. Документы сортируются по итоговому RRF score.

## Пример

Документ находится на 2-м месте в Semantic Search и на 3-м в Keyword Search. Он получает два вклада, которые суммируются, поэтому может оказаться выше документа, хорошо найденного только одним каналом.

## Типичные ошибки

- Называть RRF простым средним позиций или raw scores.
- Сравнивать напрямую similarity score и BM25 score.
- Конкатенировать списки без дедупликации документов.
- Считать, что документ обязан присутствовать во всех списках, чтобы получить RRF score.
