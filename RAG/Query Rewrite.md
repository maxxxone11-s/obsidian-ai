# Query Rewrite

Область: [[RAG/RAG|RAG]]

## Академическое определение

Query Rewrite — техника [[RAG/Query Transformation|Query Transformation]], преобразующая пользовательский запрос в самостоятельную и более понятную для retrieval форму без изменения его смысла.

## Инженерное назначение

Техника устраняет неоднозначности, вызванные историей диалога, местоимениями и неполными вопросами, чтобы embedding отражал полное поисковое намерение.

## Причина существования

Retriever обычно получает итоговую строку запроса и не восстанавливает контекст предыдущего диалога самостоятельно. Поэтому короткий вопрос может не содержать сущность, по которой требуется выполнить поиск.

## Простое объяснение

Query Rewrite переписывает вопрос так, чтобы его можно было понять без истории разговора.

## Как это работает

1. Получает текущий вопрос и необходимый контекст диалога.
2. Разрешает местоимения и неявные ссылки.
3. Формирует самостоятельный вопрос с тем же намерением.
4. Для переписанного вопроса строится embedding.
5. [[RAG/Retrieval|Retriever]] выполняет поиск.

## Пример

После обсуждения PostgreSQL вопрос «Как его установить?» преобразуется в «Как установить PostgreSQL?».

## Типичные ошибки

- Добавлять информацию, которой нет в вопросе или истории диалога.
- Выполнять Rewrite после построения embedding.
- Изменять исходное намерение пользователя.
- Путать Rewrite с генерацией финального ответа.
