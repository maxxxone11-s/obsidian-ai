# KV Cache

## Академическое определение

KV Cache — механизм кэширования матриц Key и Value для уже обработанных токенов во время авторегрессионной генерации.

Вместо повторного вычисления Key и Value для всей последовательности при генерации каждого нового токена модель сохраняет ранее вычисленные представления и вычисляет только Key и Value нового токена.

## Инженерное назначение

KV Cache существенно уменьшает объем повторных вычислений при генерации текста и ускоряет inference больших языковых моделей.

В реальной LLM-системе он живет внутри одного generation-запроса и помогает модели быстро продолжать уже начатую последовательность.

## Причина существования

Без KV Cache модель была бы вынуждена заново вычислять Q, K и V для всех предыдущих токенов после генерации каждого нового токена.

Это приводило бы к огромному количеству лишних вычислений во время autoregressive generation.

## Простое объяснение

После обработки токена его Key и Value больше не изменяются. Поэтому их можно сохранить в памяти и использовать повторно.

При появлении нового токена вычисляются только его Embedding, Query, Key и Value.

## Как это работает

Процесс генерации:

1. Новый токен проходит [[Embedding Layer]].
2. Вычисляются только `Q_new`, `K_new` и `V_new`.
3. `K_new` и `V_new` добавляются в KV Cache.
4. `Q_new` сравнивается со всеми сохраненными Key.
5. Через веса Attention используется соответствующий Value.
6. Старые Key и Value не пересчитываются.

Старые Query не сохраняются, потому что они уже выполнили свою задачу при генерации предыдущих токенов.

KV Cache возможен благодаря Causal Mask: будущие токены не могут изменить представления прошлых токенов, поэтому ранее вычисленные Key и Value остаются корректными.

## Пример

```text
Было сгенерировано:
Я | люблю | Transformer

KV Cache содержит:
K1 V1
K2 V2
K3 V3

Генерируется новый токен:
Q4
K4
V4

Q4 сравнивается с K1...K4.
Старые K и V повторно не вычисляются.
```

## Типичные ошибки

- Считать, что кэшируются Embedding.
- Считать, что кэшируются Query.
- Считать, что KV Cache работает между разными запросами пользователя.
- Не понимать зависимость KV Cache от Causal Mask.
