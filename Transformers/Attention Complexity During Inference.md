# Attention Complexity During Inference

Область: [[Transformers/Transformers|Transformers]]

## Академическое определение

Attention Complexity During Inference — вычислительная стоимость attention-операций при генерации новых токенов.

KV Cache устраняет повторное вычисление Key и Value, но не устраняет необходимость сравнивать Query нового токена со всеми ранее сохраненными Key.

## Инженерное назначение

Эта концепция объясняет, почему генерация постепенно замедляется при увеличении длины контекста даже при использовании [[KV Cache]].

Она помогает инженеру понимать ограничения long-context inference и стоимость обслуживания LLM.

## Причина существования

Каждый новый токен должен определить важность всех предыдущих токенов.

Поэтому операция Attention продолжает зависеть от длины контекста.

## Простое объяснение

Чем длиннее история диалога, тем больше Key необходимо просмотреть новому Query.

KV Cache убирает повторное вычисление старых K/V, но не отменяет сравнение нового Query со всей историей.

## Как это работает

Для нового токена вычисляется один Query:

```text
Q_new
```

Затем вычисляются Attention Scores:

```text
Q_new × K1
Q_new × K2
...
Q_new × Kn
```

Стоимость генерации одного нового токена продолжает расти вместе с длиной последовательности.

## Пример

```text
100 токенов   → около 100 сравнений
1000 токенов  → около 1000 сравнений
10000 токенов → около 10000 сравнений
```

## Типичные ошибки

- Считать, что KV Cache полностью устраняет рост вычислений.
- Путать повторное вычисление K/V со сравнением Query со всеми Key.
