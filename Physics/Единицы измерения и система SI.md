# Единицы измерения и система SI

Область: [[Physics/Physics|Physics]]

## Академическое определение

Единица измерения — установленная величина, относительно которой выражается результат измерения. SI — международная система стандартных единиц.

## Инженерное назначение

Обеспечивает единый формат измерений и предотвращает неоднозначность при вычислениях и обмене данными.

## Причина существования

Без общей системы единиц одинаковые численные значения могли бы обозначать физически разные результаты.

## Простое объяснение

Единица показывает, в чём измерена величина.

## Как это работает

Основные единицы SI из урока: метр для длины, килограмм для массы, секунда для времени, кельвин для температуры и ампер для электрического тока. Производные единицы строятся из основных: скорость измеряется в `м/с`, ускорение — в `м/с²`, а `1 Н = 1 кг·м/с²`.

## Пример

Единица площади в SI — `м²`.

## Типичные ошибки

- Смешивать единицы разных систем без преобразования.
- Записывать скорость без указания единицы.
- Путать обозначение величины с обозначением единицы.
