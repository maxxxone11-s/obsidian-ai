# Дифференциальное уравнение

Область: [[Physics/Physics|Physics]]

## Академическое определение

Дифференциальное уравнение — уравнение, содержащее производную неизвестной функции и задающее закон её изменения.

## Инженерное назначение

Используется для моделирования динамических систем, состояние которых развивается во времени.

## Причина существования

Во многих физических задачах известна не сама функция состояния, а правило, по которому она изменяется.

## Простое объяснение

Обычное уравнение ищет число, а дифференциальное уравнение — функцию, которая изменяется по заданному правилу.

## Как это работает

Уравнение `dv/dt = 2` означает, что скорость увеличивается на `2 м/с` каждую секунду. Оно не задаёт единственное решение без начального условия. При `v(0) = 0` решение равно `v(t) = 2t`, а при `v(0) = 5` — `v(t) = 5 + 2t`. Для постоянного ускорения общая связь имеет вид `v(t) = v₀ + at`.

## Пример

Если `dv/dt = 3` и `v(0) = 4 м/с`, то через две секунды `Δv = 3·2 = 6 м/с`, а текущая скорость равна `10 м/с`.

## Типичные ошибки

- Считать `dv/dt` текущей скоростью: это скорость изменения скорости, то есть ускорение.
- Искать единственное решение без начального условия.
- Путать правило изменения с текущим значением величины.
- Не учитывать единицы измерения производной.
