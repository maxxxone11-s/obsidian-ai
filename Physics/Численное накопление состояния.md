# Численное накопление состояния

Область: [[Physics/Physics|Physics]]

## Академическое определение

Численное накопление состояния — приближённое вычисление непрерывного изменения системы через последовательные шаги малого размера `dt`.

## Инженерное назначение

Позволяет решать физические модели кодом, когда аналитическое решение сложно или неизвестно.

## Причина существования

Компьютер выполняет дискретные операции и не может напрямую обработать бесконечно малые изменения.

## Простое объяснение

Время разбивается на маленькие шаги; после каждого шага обновляются скорость и положение.

## Как это работает

Из ускорения обновляется скорость: `velocity += acceleration·dt`. Затем из скорости обновляется положение: `position += velocity·dt`. Это соответствует приближениям `Δv ≈ a·dt` и `Δx ≈ v·dt`. Новые значения становятся начальными для следующего шага.

## Пример

При `acceleration = 2 м/с²`, `velocity = 0` и `dt = 1 с` последовательные значения скорости равны `2`, `4`, `6 м/с`. Значение `velocity = 6` описывает текущую скорость, а не пройденный путь.

## Типичные ошибки

- Путать переменную `velocity` с расстоянием.
- Использовать слишком большой `dt` и ожидать высокой точности.
- Забывать умножать скорость изменения на `dt`.
- Не учитывать порядок обновления переменных.
