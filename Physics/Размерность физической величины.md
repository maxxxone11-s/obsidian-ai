# Размерность физической величины

Область: [[Physics/Physics|Physics]]

## Академическое определение

Размерность показывает физический тип величины и выражает её через основные величины, например длину `L`, массу `M` и время `T`.

## Инженерное назначение

Используется для проверки согласованности физических формул и определения физического типа результата вычисления.

## Причина существования

Разные единицы могут описывать один физический тип величины, поэтому нужен способ описывать этот тип независимо от системы единиц.

## Простое объяснение

Размерность показывает не конкретную единицу, а то, из каких физических типов состоит величина.

## Как это работает

- длина: `[L]`;
- масса: `[M]`;
- время: `[T]`;
- скорость: `[v] = L/T = LT⁻¹`;
- ускорение: `[a] = L/T² = LT⁻²`;
- площадь: `[S] = L²`.

Размерности обеих частей корректной формулы должны совпадать.

## Пример

Для `s = vt` размерность правой части равна `[v][t] = (L/T)·T = L`, то есть совпадает с размерностью пути.

## Типичные ошибки

- Путать размерность с единицей измерения.
- Считать `S` размерностью площади: это обозначение величины, а размерность площади равна `L²`.
- Считать размерностно согласованную формулу автоматически физически правильной.
