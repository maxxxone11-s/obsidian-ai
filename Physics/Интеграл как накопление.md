# Интеграл как накопление

Область: [[Physics/Physics|Physics]]

## Академическое определение

Интеграл вычисляет накопленное значение величины как предел суммы большого количества малых вкладов.

## Инженерное назначение

Позволяет восстанавливать путь по скорости, скорость по ускорению и другие накопленные состояния по известной скорости их изменения.

## Причина существования

Когда скорость изменения непостоянна, простое умножение одного значения на время не даёт корректного результата.

## Простое объяснение

Интеграл складывает множество маленьких изменений и получает общий результат.

## Как это работает

При постоянной скорости используется `s = vt`. При переменной скорости путь или перемещение вычисляется как `s = ∫v(t)dt`. В численном приближении каждый малый вклад равен `Δs ≈ v·dt`, после чего вклады суммируются. Запись `∫₀³v(t)dt` означает накопление от `t = 0` до `t = 3`.

## Пример

Для скоростей `2`, `4` и `6 м/с` на трёх интервалах по секунде сумма путей равна `2·1 + 4·1 + 6·1 = 12 м`. Для `v(t) = 2t` путь за первые три секунды равен `∫₀³2t dt = 9 м`.

## Типичные ошибки

- Использовать `s = vt` при переменной скорости без дополнительного анализа.
- Не учитывать границы интегрирования.
- Путать `dt` с полной длительностью процесса.
- Считать результат интегрирования скорости скоростью, а не перемещением.
