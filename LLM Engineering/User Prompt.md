# User Prompt

## Академическое определение

User Prompt — переменная часть входного контекста, содержащая данные конкретного запроса пользователя и дополнительный контекст, сформированный приложением.

## Инженерное назначение

User Prompt передает модели актуальные данные, необходимые для решения текущей задачи.

## Причина существования

Он отделяет изменяемую информацию от постоянных инструкций приложения.

## Простое объяснение

В production User Prompt обычно проектирует backend, а не сам пользователь.

## Как это работает

```text
Пользователь
    ↓
Backend
    ↓
Добавление истории, документов, логов, результатов поиска
    ↓
User Prompt
    ↓
LLM
```

## Пример

```text
Контекст
Код
Traceback
Вопрос
```

## Типичные ошибки

- Передавать модели только текст пользователя.
- Не добавлять необходимый контекст приложения.
