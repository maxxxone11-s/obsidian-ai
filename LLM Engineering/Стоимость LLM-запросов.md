# Стоимость LLM-запросов

## Академическое определение

Стоимость LLM-запроса определяется количеством входных и выходных токенов, обработанных моделью, с учётом тарифов конкретной модели и провайдера, а не только числом запросов или длиной пользовательского сообщения.

## Инженерное назначение

Понимание структуры стоимости позволяет прогнозировать расходы AI-системы и принимать измеримые решения по их сокращению.

## Причина существования

Обработка токенов требует вычислительных ресурсов. Провайдеры тарифицируют input и output tokens, причём их цены могут различаться.

## Простое объяснение

Пользователь может написать одно слово, но backend способен добавить тысячи токенов инструкций, истории и документов. Оплачивается весь обработанный контекст и ответ.

## Как это работает

```text
Стоимость =
  input_tokens × input_rate
  + output_tokens × output_rate
```

Input включает system prompt, историю, summary, tool results, RAG-документы и user prompt. Output включает сгенерированный моделью ответ.

## Пример

Пользователь пишет «Привет», но backend отправляет system prompt, историю, summary, документы и сообщение пользователя. В расчёт стоимости входят токены всех этих компонентов и токены ответа.

## Типичные ошибки

- Считать, что стоимость зависит только от сообщения пользователя.
- Игнорировать стоимость большого контекста.
- Не учитывать выходные токены или различие тарифов input/output.
