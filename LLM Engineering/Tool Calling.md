# Tool Calling

## Академическое определение

Tool Calling — механизм взаимодействия LLM с внешними возможностями приложения через стандартизированные интерфейсы инструментов.

## Инженерное назначение

Механизм унифицирует подключение функций, браузеров, поиска, баз данных, файловых систем и MCP-серверов к LLM-приложению.

## Причина существования

Современным LLM-приложениям нужны возможности шире локальных функций. Обобщённый интерфейс tool позволяет одинаково оркестрировать разные виды внешних действий.

## Простое объяснение

Function Calling — частный случай Tool Calling: не каждый tool является Python-функцией.

## Как это работает

1. Приложение объявляет доступные инструменты и их контракты.
2. Модель выбирает подходящий tool.
3. Backend выполняет разрешённое действие.
4. Результат возвращается модели.

## Пример

```text
Tool
├── Function
├── Browser
├── Search
├── Database
└── MCP server
```

## Типичные ошибки

- Использовать Tool Calling и Function Calling как полностью одинаковые понятия.
- Считать, что tool обязательно является Python-функцией.
