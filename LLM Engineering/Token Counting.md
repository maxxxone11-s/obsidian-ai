# Token Counting

## Академическое определение

Token Counting — процесс вычисления количества токенов во входном и выходном контексте модели для контроля Context Window, стоимости запросов и корректной работы приложения.

## Инженерное назначение

Подсчёт позволяет заранее определить, поместится ли запрос в Context Window, оценить стоимость и выбрать стратегию сокращения контекста.

## Причина существования

Ограничения и стоимость LLM API выражаются в токенах, а не в символах, байтах, словах или строках.

## Простое объяснение

Backend сначала оценивает запрос тем же или совместимым токенизатором, а затем решает, можно ли безопасно отправить данные модели.

## Как это работает

1. Выбирается токенизатор конкретной модели.
2. Учитывается содержимое сообщений и служебный overhead их структуры.
3. К input tokens добавляется бюджет output tokens.
4. Сумма сравнивается с [[Context Window]].
5. Значение также используется для оценки стоимости.

## Пример

```python
import tiktoken

encoding = tiktoken.encoding_for_model("gpt-4o-mini")
tokens = encoding.encode(text)
count = len(tokens)
```

Для полного chat-запроса дополнительно нужно учитывать служебные токены формата сообщений конкретного API.

## Типичные ошибки

- Считать символы вместо токенов.
- Предполагать, что одно слово всегда равно одному токену.
- Использовать токенизатор другой модели.
- Игнорировать служебный overhead сообщений.
