# Function Calling

Область: [[LLM Engineering/LLM Engineering|LLM Engineering]]

## Академическое определение

Function Calling — механизм, при котором LLM не выполняет функцию самостоятельно, а формирует структурированный запрос на её вызов. Приложение решает, выполнять ли запрос, вызывает функцию и передаёт результат обратно модели.

## Инженерное назначение

Механизм безопасно подключает к генерации ответа внешние возможности приложения: API, базы данных, сервисы и вычисления.

## Причина существования

LLM не имеет прямого доступа к внешнему миру, актуальным данным и Python-коду. Между намерением модели и реальным действием необходим контролируемый backend-слой.

## Простое объяснение

Модель сообщает приложению, какую функцию и с какими аргументами стоит вызвать. Сам вызов выполняет backend.

## Как это работает

1. Пользователь отправляет запрос.
2. LLM сопоставляет запрос с доступными [[Function Schema|схемами функций]].
3. Модель возвращает структурированный function call.
4. Backend проверяет запрос и вызывает разрешённую функцию.
5. Результат передаётся модели как tool result.
6. Модель формирует окончательный ответ.

## Пример

```text
Пользователь: Какая погода в Берлине?
LLM: get_weather(city="Berlin")
Backend: вызывает Weather API и возвращает результат модели
LLM: формирует ответ пользователю
```

## Типичные ошибки

- Считать, что LLM самостоятельно вызывает Python-функции.
- Давать модели прямой доступ к выполнению произвольного кода.
- Путать Function Calling с обычной генерацией текста.
