# Model Routing

## Академическое определение

Model Routing — механизм выбора языковой модели на основании требований конкретного запроса с целью сбалансировать стоимость, задержку, доступность и качество результата.

## Инженерное назначение

Router позволяет использовать минимально достаточную модель для каждой задачи и направлять сложные запросы к более способным моделям.

## Причина существования

Задачи различаются по сложности и требованиям. Использование одной дорогой модели для всех запросов расточительно, а одной слабой — ухудшает качество.

## Простое объяснение

Backend оценивает задачу и выбирает подходящую модель до выполнения основного LLM-запроса.

## Как это работает

1. Router извлекает признаки запроса: тип задачи, сложность, допустимую задержку и требования к качеству.
2. Применяет правила или отдельный классификатор.
3. Выбирает модель и провайдера.
4. При необходимости использует fallback или каскад от дешёвой модели к дорогой.
5. Записывает решение и метрики качества.

## Пример

```text
Перевод одного слова → mini model
Анализ сложного договора → более мощная модель
```

## Типичные ошибки

- Использовать одну модель для всех задач.
- Считать, что модель самостоятельно выбирает себя.
- Маршрутизировать только по длине запроса, игнорируя сложность.
