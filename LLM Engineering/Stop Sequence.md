# Stop Sequence

## Академическое определение

Stop Sequence — параметр генерации, задающий одну или несколько последовательностей символов, при появлении которых генерация ответа должна быть немедленно остановлена.

## Инженерное назначение

Stop Sequence позволяет завершать генерацию в заранее определенной точке, если приложение использует собственные шаблоны или специальные маркеры.

## Причина существования

Этот параметр позволяет приложению самостоятельно определить границу окончания ответа независимо от поведения модели.

## Простое объяснение

Если модель сгенерировала указанную последовательность, API прекращает дальнейшую генерацию.

## Как это работает

```text
LLM генерирует токены
    ↓
Появляется stop-последовательность
    ↓
Генерация завершается
    ↓
Ответ возвращается приложению
```

## Пример

```python
stop = ["END"]
```

## Типичные ошибки

- Использовать `stop` вместо [[Structured Output]].
- Рассматривать `stop` как средство проверки структуры данных.
