# Context Window

## Академическое определение

Context Window — максимальное количество токенов, которое модель может одновременно учитывать при обработке одного запроса, включая входной контекст и пространство, зарезервированное для генерации ответа.

## Инженерное назначение

Окно контекста ограничивает объём информации, который backend может передать модели за один запрос, и определяет необходимость управления памятью приложения.

## Причина существования

Архитектура Transformer способна одновременно обработать только ограниченное количество токенов. Инструкции, история, документы и ожидаемый ответ должны укладываться в поддерживаемый моделью предел.

## Простое объяснение

Context Window — общий бюджет токенов для system prompt, истории, текущего запроса, результатов инструментов, найденных документов и будущего ответа.

## Как это работает

```text
Context Window =
  System Prompt
  + Conversation History
  + User Prompt
  + Tool Results
  + Retrieved Documents
  + Output Tokens
```

Перед отправкой запроса backend оценивает сумму входных токенов и зарезервированных output tokens. Если сумма превышает лимит модели, контекст необходимо сократить.

## Пример

Модель поддерживает 128 000 токенов. Вход уже занимает 127 900, а `max_tokens = 300`. Потенциальный объём равен 128 200 токенам и превышает лимит.

## Типичные ошибки

- Считать, что Context Window ограничивает только пользовательский запрос.
- Не учитывать место для будущего ответа.
- Думать, что модель самостоятельно управляет размером контекста.
