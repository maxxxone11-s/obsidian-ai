# Function Schema

Область: [[LLM Engineering/LLM Engineering|LLM Engineering]]

## Академическое определение

Function Schema — структурированное описание функции, содержащее её назначение и параметры и передаваемое LLM для выбора функции и формирования корректных аргументов.

## Инженерное назначение

Схема позволяет модели понимать доступные возможности приложения без знания реализации функций и служит контрактом между LLM и backend.

## Причина существования

LLM работает с интерфейсом функции, а не с её исходным кодом. Без явной схемы модель не знает допустимых аргументов, их типов и назначения инструмента.

## Простое объяснение

Function Schema описывает, что делает функция и какие данные принимает, но не раскрывает, как она реализована.

## Как это работает

1. Backend передаёт модели имя, описание и параметры функции.
2. Параметры обычно задаются через [[JSON Schema]].
3. LLM сопоставляет запрос пользователя с описанием.
4. При выборе функции модель формирует аргументы по заданной схеме.

## Пример

```yaml
name: get_weather
description: Возвращает текущую погоду в городе
parameters:
  city:
    type: string
```

## Типичные ошибки

- Использовать непонятные названия функций.
- Давать слишком короткие или пересекающиеся описания.
- Описывать реализацию функции вместо её интерфейса.
