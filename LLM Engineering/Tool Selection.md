# Tool Selection

## Академическое определение

Tool Selection — процесс, в котором LLM анализирует пользовательский запрос и описания доступных инструментов, выбирает подходящий инструмент и формирует аргументы для его вызова.

## Инженерное назначение

Процесс автоматически маршрутизирует пользовательские запросы к возможностям приложения на основании смысла запроса.

## Причина существования

Пользователь формулирует задачу, а не выбирает внутреннюю функцию backend. Система должна преобразовать естественный язык в конкретный интерфейс инструмента.

## Простое объяснение

Модель выбирает функцию по её назначению и описанию, а не только по имени.

## Как это работает

1. Модель получает запрос и набор [[Function Schema|схем инструментов]].
2. Сопоставляет смысл запроса с описаниями.
3. Выбирает инструмент либо решает ответить без него.
4. Генерирует аргументы выбранного инструмента.

## Пример

```text
Запрос: Какая погода в Париже?
Выбор: get_weather
Аргументы: {"city": "Paris"}
```

## Типичные ошибки

- Создавать несколько инструментов с одинаковым назначением.
- Давать инструментам пересекающиеся описания.
- Считать, что backend семантически выбирает функцию вместо модели.
