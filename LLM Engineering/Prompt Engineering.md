# Prompt Engineering

## Академическое определение

Prompt Engineering — процесс проектирования входного контекста LLM так, чтобы поведение модели было максимально предсказуемым, воспроизводимым и соответствовало задаче.

## Инженерное назначение

Prompt Engineering управляет поведением модели без изменения самой модели.

## Причина существования

LLM является вероятностной системой и требует явно сформулированного контекста для получения стабильных результатов.

## Простое объяснение

Prompt Engineering — это проектирование входных данных, а не поиск магических формулировок.

- Пытаться менять модель вместо улучшения prompt.
