# Cost Optimization

## Академическое определение

Cost Optimization — совокупность инженерных решений, уменьшающих количество обрабатываемых токенов, стоимость выбранной модели и число лишних обращений к LLM без неприемлемого ухудшения качества приложения.

## Инженерное назначение

Оптимизация снижает стоимость эксплуатации AI-приложения и делает расходы предсказуемыми при росте нагрузки.

## Причина существования

Длинный контекст, мощные модели и избыточные обращения быстро увеличивают стоимость. Одинаковое качество часто можно получить более экономной архитектурой.

## Простое объяснение

Нужно не просто уменьшать число запросов, а выбирать минимально достаточную модель и передавать ей только действительно нужный контекст.

## Как это работает

Основные стратегии:

1. Сокращать контекст через [[Memory Management]].
2. Ограничивать разумный бюджет ответа через [[Max Tokens]].
3. Использовать [[Model Routing]].
4. Применять обычный cache и [[Prompt Caching]].
5. Выполнять [[Исключение ненужных вызовов LLM|простые задачи без LLM]].
6. Измерять токены, стоимость и качество до и после оптимизации.

## Пример

Вместо истории из 150 сообщений backend передаёт summary старой части и последние 20 сообщений. Это уменьшает input tokens, сохраняя релевантный контекст.

## Типичные ошибки

- Оптимизировать короткий user prompt вместо длинной истории.
- Использовать самую дорогую модель для всех задач.
- Отправлять LLM задачи, которые надёжнее решаются backend-кодом.
- Снижать стоимость без контроля качества ответа.
