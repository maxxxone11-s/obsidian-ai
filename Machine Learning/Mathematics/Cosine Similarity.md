# Cosine Similarity

## Академическое определение

Cosine Similarity — мера сходства двух ненулевых векторов, равная косинусу угла между ними:

$$
\operatorname{cos\_sim}(a,b)=\frac{a\cdot b}{\lVert a\rVert\lVert b\rVert}
$$

## Инженерное назначение

Метрика используется для сравнения направления embeddings и ранжирования документов по семантической близости к запросу.

## Причина существования

Для многих embeddings направление несёт больше полезной информации, чем длина. Cosine Similarity позволяет сравнивать направления независимо от масштаба векторов.

## Простое объяснение

Главное — куда смотрят векторы. Чем меньше угол между направлениями, тем выше сходство.

## Как это работает

1. Вычисляется скалярное произведение векторов.
2. Результат делится на произведение их норм.
3. Для одинакового направления получается значение `1`, для ортогональных направлений — `0`, для противоположных — `-1`.
4. Документы сортируются по оценке сходства с embedding запроса.

## Пример

Векторы `[1, 1]` и `[100, 100]` имеют разную длину, но одинаковое направление, поэтому их cosine similarity равен `1`.

## Типичные ошибки

- Путать Cosine Similarity со скалярным произведением.
- Считать, что метрика измеряет физическое расстояние между точками.
- Утверждать, что Cosine Similarity всегда лучше Euclidean Distance без учёта модели embeddings.
- Забывать, что нулевой вектор не имеет определённого направления.
